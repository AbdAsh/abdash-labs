abdash labs

Seven AI applications sharing one account, one database and one deploy.

Built by Abdulrahman Mahmutoglu · Source

Each one proves a different thing about applied AI engineering, and each opens on a finished example — real captured output, instant, no signup and nothing to prepare. The live tool is always one click further in.

The seven

  • Recto Multi-document notebooks where every answer names which document it came from.
  • AskSheet Ask a spreadsheet in English. The data never leaves your browser — check the network tab.
  • Critiq SEO and answer-engine review of any URL. The self-audit of abdash.net is not flattering.
  • RAG Lab Which chunking actually wins? Benchmarks, not vibes — and the expensive model lost.
  • GraphRead A document as an entity graph. Click any edge for the sentence that justified it.
  • PlaneMode A language model running entirely in your browser. Turn on airplane mode and keep going.
  • Concierge ↗ A voice agent that has read the CV, embedded on the portfolio. Interrupt it mid-sentence.
One anonymous account works across all of them, created on first paint and never asked for. Isolation between visitors is enforced by Postgres row-level security and verified by cross-user tests, not asserted. Read the source.
